# Gorecraft - Modern Minecraft Sunucusu

Gorecraft, modern ve kullanıcı dostu tasarımıyla dikkat çeken bir Minecraft sunucusu web sitesidir.

## 🎮 Özellikler

- **Modern Tasarım**: Gradient renkler ve smooth animasyonlar
- **Responsive**: Mobil ve masaüstü cihazlarda mükemmel görünüm
- **İndirme Sistemi**: Tek tıkla gorecraft2.0 dosyası indirme
- **Animasyonlar**: Float efektleri, parallax scroll ve mouse takip
- **Bildirim Sistemi**: Kullanıcı dostu bildirimler
- **Vercel Ready**: Vercel deploy için optimize edilmiş

## 🚀 Kurulum ve Deploy

### Local Development

```bash
# Proje klasörüne gidin
cd "rat site"

# Local sunucu başlatın
npm start
# veya
python3 -m http.server 3000
```

### Vercel Deploy

1. Projeyi GitHub'a push edin
2. Vercel hesabınızda "New Project" oluşturun
3. GitHub repository'nizi seçin
4. Deploy butonuna tıklayın

## 📁 Dosya Yapısı

```
rat site/
├── index.html          # Ana sayfa
├── style.css          # Stil dosyası
├── script.js          # JavaScript fonksiyonları
├── gorecraft2.0.txt   # İndirilebilir dosya
├── package.json       # Proje bilgileri
├── vercel.json        # Vercel yapılandırması
└── README.md          # Bu dosya
```

## 🎨 Tasarım Özellikleri

- **Renk Paleti**: Yeşil tonları ve gradient efektler
- **Font**: Inter (Google Fonts)
- **Animasyonlar**: CSS animations ve JavaScript effects
- **Responsive**: Mobile-first yaklaşım
- **Dark Theme**: Modern dark mode tasarım

## ⚡ JavaScript Fonksiyonları

- **Smooth Scroll**: Navigation linkleri için yumuşak kaydırma
- **Download System**: gorecraft2.0 dosyası indirme
- **Notification System**: Kullanıcı bildirimleri
- **Scroll Effects**: Parallax ve navbar efektleri
- **Mouse Tracking**: Floating blocks mouse takibi
- **Keyboard Shortcuts**: Ctrl+D indirme, ESC bildirim kapatma
