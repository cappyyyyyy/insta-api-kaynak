# GoreCraft Minecraft Mod

## Description
GoreCraft is a comprehensive Minecraft modification designed to enhance your gameplay experience with new features, blocks, and mechanics.

## Features
- Custom crafting recipes and items
- Enhanced gameplay mechanics
- Performance optimizations
- New block types and textures
- Adventure-focused gameplay elements

## Installation
1. Download Minecraft Forge for Minecraft 1.18.2
2. Place the GoreCraft jar file in your mods folder
3. Launch Minecraft with the Forge profile

## Compatibility
- Minecraft: 1.18.2 - 1.19.x
- Forge: 40.0.0+
